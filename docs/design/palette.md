# Paleta visual de Zul Luz

Referencia: captura de storefront entregada el 12 de septiembre de 2026. Los tonos son aproximaciones visuales aplicadas como tokens en `app/globals.css`.

| Uso | Token | Hex |
|---|---|---|
| Aguamarina de identidad; header, footer y campos suaves | `blush` | `#ADD7D9` |
| Teal oscuro; logotipo, botones, enlaces y texto de énfasis | `wine` | `#155B5E` |
| Teal profundo; texto principal y contraste | `dark` | `#143E40` |
| Blanco cálido; fondos de lectura | `cream` | `#FCFCFA` |
| Aguamarina pálido; hover, drawers y superficies secundarias | `blush-light` | `#E7F2F1` |
| Gris verdoso; texto secundario | `muted` | `#687776` |
| Aqua desaturado; bordes | `border` | `#B9DCDD` |
| Cobre satinado; acentos editoriales derivados de la fotografía | `terracotta` | `#B97858` |

El cobre se reserva para detalles, chips o acentos sobre fondo claro; no debe utilizarse como color de texto pequeño para preservar contraste.
